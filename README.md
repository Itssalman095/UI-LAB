# 🧪 UI-LAB

A growing collection of front-end experiments: micro-interactions, animations, and UI components. Every project lives in its own folder and runs on its own, with no build step required.

This repo is my playground for learning and practicing **HTML, CSS, JavaScript, SVG, and animation**. New experiments get added regularly, so browse the folders above to see what's inside.

---

## 📖 About

UI-LAB started as a place to turn UI ideas into working code. Instead of only reading tutorials, I rebuild interesting interfaces from scratch, break them, and figure out how they work. Each experiment is small and focused on one idea, which keeps it easy to read, easy to learn from, and easy to reuse.

---

## 🎯 What You'll Find Here

- **Button animations:** hover, click, loading, and success states
- **Micro-interactions:** small details that make an interface feel alive
- **Animated icons and SVG work:** drawn and animated by hand
- **UI components:** cards, dashboards, toggles, and more
- **Cursor-driven effects:** elements that react to the mouse
- **CSS-only tricks:** things built without any JavaScript

---

## 💡 Concepts Practiced

- CSS keyframes, transitions, and custom properties
- Flexbox and Grid layouts
- SVG shapes, paths, and animation
- DOM manipulation and event handling in vanilla JavaScript
- Animation libraries such as GSAP and the Web Animations API
- Accessibility basics: ARIA labels, keyboard support, and `prefers-reduced-motion`
- Responsive design and clean, readable code

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/Itssalman095/UI-LAB.git
cd UI-LAB
```

Open any project's `index.html` in your browser, or serve the folder with a local server such as the VS Code **Live Server** extension or `npx serve`.

> Some projects load Google Fonts or a library like GSAP from a CDN, so an internet connection is needed for them to look right.

---

## 📁 Structure

Each experiment is a standalone folder:

```
UI-LAB/
├── Project-Name/
│   ├── index.html
│   ├── style.css
│   └── script.js     (optional)
├── ...
└── README.md
```

- Folder names describe the project, e.g. `Send-Button-Animation`
- Projects don't depend on each other, so you can copy any folder and use it elsewhere
- Plain HTML, CSS, and JS only, with no frameworks or build tools
